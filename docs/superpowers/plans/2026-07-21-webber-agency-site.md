# Webber Agency Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a single-page marketing site for Webber, a branding/web-design/development agency, in a light minimal aesthetic with Framer-grade scroll motion.

**Architecture:** Nine section components compose a single page. Each section is a pure renderer over exactly one typed module in `content/` — sections contain no copy. All animation lives in five reusable primitives under `components/motion/`; these are the only files importing `motion/react`. This keeps copy swappable by data edit and animation behaviour changeable in one place.

**Tech Stack:** Next.js (App Router, TypeScript strict), Tailwind CSS v4, shadcn/ui on Base UI (`@base-ui/react`), `motion` (Motion for React), `lucide-react`, Vitest + React Testing Library.

## Global Constraints

- Spec of record: `docs/superpowers/specs/2026-07-21-webber-agency-site-design.md`. Where this plan and the spec disagree, the spec wins.
- Palette tokens, exact values: `--color-ground: #FAFAF9`, `--color-ink: #0A0A0A`, `--color-muted: #6B6B6B`, `--color-hairline: rgba(10,10,10,0.08)`, `--color-accent: #C4512A`, `--color-ground-dark: #0A0A0A`, `--color-ink-dark: #FAFAF9`.
- Accent `#C4512A` is used **only** on bracket section labels and active/hover states. Never on large surfaces.
- Typeface: General Sans, self-hosted, weights 400/500/600 only. Fallback stack `ui-sans-serif, system-ui, sans-serif`.
- Display type: `clamp(2.5rem, 7vw, 6.5rem)`, `tracking-[-0.03em]`, `leading-[0.95]`.
- Section labels use the `< bracketed lowercase >` form.
- Max content width `1280px`; gutters `1.5rem` mobile / `3rem` desktop.
- **Reduced motion is a hard requirement.** Every motion primitive must render children statically — no transform, no transition, no scroll listener — when `prefers-reduced-motion: reduce` is set.
- All content is fabricated placeholder copy. Every file in `content/` starts with the placeholder header comment defined in Task 2.
- Single page only. Nav links are in-page anchors. No `/work/[slug]` routes, no CMS, no contact form, no analytics.
- Out of scope, do not add: Mux HLS video, liquid-glass card, `#5ed29c` green.
- TypeScript strict mode. `next build` and `vitest run` must pass before any task is considered complete.

- [ ] **Step 3: Add the font fetch script**

Fontshare serves woff2 under rotating content-hash URLs, so resolve them from the CSS endpoint rather than hardcoding.

Create `scripts/fetch-fonts.sh`:

```bash
#!/usr/bin/env bash
# Resolves General Sans woff2 URLs from the Fontshare CSS endpoint and downloads
# them to app/fonts/. URLs are content hashes and rotate, so never hardcode them.
set -euo pipefail

DEST="app/fonts"
API='https://api.fontshare.com/v2/css?f%5B%5D=general-sans@400,500,600&display=swap'
mkdir -p "$DEST"

CSS=$(curl -sfL "$API" -A "Mozilla/5.0")

# The endpoint returns @font-face blocks ordered 400, 500, 600.
i=0
for weight in 400 500 600; do
  i=$((i + 1))
  url=$(printf '%s' "$CSS" | grep -o "//cdn\.fontshare\.com/[^']*\.woff2" | sed -n "${i}p")
  if [ -z "$url" ]; then
    echo "Could not resolve woff2 URL for weight $weight" >&2
    exit 1
  fi
  curl -sfL "https:$url" -o "$DEST/GeneralSans-$weight.woff2"
  echo "Downloaded $DEST/GeneralSans-$weight.woff2"
done
```

```bash
chmod +x scripts/fetch-fonts.sh && ./scripts/fetch-fonts.sh
```

Expected: three lines of `Downloaded ...`. Verify the files are genuine fonts, not error pages:

```bash

```

Expected: each reports `Web Open Font Format (Version 2)`. Each file should be roughly 20–30KB.

```ts
import "@testing-library/jest-dom/vitest"
import { vi } from "vitest"

/** Set the reduced-motion preference for the current test. */
export function setReducedMotion(reduce: boolean) {
  vi.stubGlobal(
    "matchMedia",
    vi.fn().mockImplementation((query: string) => ({
      matches: query.includes("prefers-reduced-motion") ? reduce : false,
      media: query,
      onchange: null,
      addListener: vi.fn(),
      removeListener: vi.fn(),
      addEventListener: vi.fn(),
      removeEventListener: vi.fn(),
      dispatchEvent: vi.fn(),
    }))
  )
}

setReducedMotion(false)

// jsdom lacks IntersectionObserver; Motion's viewport detection needs it.
vi.stubGlobal(
  "IntersectionObserver",
  class {
    observe() {}
    unobserve() {}
    disconnect() {}
    takeRecords() {
      return []
    }
  }
)
```

```tsx
  items: T[]
  renderItem: (item: T, index: number) => React.ReactNode

  items,
  renderItem,
  className,

      </div>

          key={i}
          className="md:sticky md:top-24"
          style={{
            // Each card sits slightly lower and smaller than the one above it.
            top: `calc(6rem + ${i * 1.5}rem)`,
            zIndex: i + 1,
          }}
        >
          <div
            className="origin-top transition-transform duration-300"
            style={{ paddingBottom: `${i * 0.5}rem` }}
          >
            {renderItem(item, i)}
          </div>
        </div>
      ))}
    </div>
```

```tsx
"use client"

import * as React from "react"
import { motion, useMotionValue, useSpring } from "motion/react"
import { useMotionOk } from "./use-motion-ok"
import { cn } from "@/lib/utils"

type MagneticButtonProps = {
  href: string
  children: React.ReactNode
  className?: string
}

const BASE =
  "inline-flex items-center justify-center gap-2 rounded-full bg-ink px-7 py-4 text-sm font-medium text-ground transition-colors hover:bg-accent focus-visible:outline-2 focus-visible:outline-offset-4 focus-visible:outline-accent"

export function MagneticButton({
  href,
  children,
  className,
}: MagneticButtonProps) {
  const motionOk = useMotionOk()
  const ref = React.useRef<HTMLAnchorElement>(null)
  const x = useMotionValue(0)
  const y = useMotionValue(0)
  const sx = useSpring(x, { stiffness: 200, damping: 18 })
  const sy = useSpring(y, { stiffness: 200, damping: 18 })

  if (!motionOk) {
    return (
      <a href={href} className={cn(BASE, className)}>
        {children}
      </a>
    )
  }

  function handleMove(e: React.MouseEvent<HTMLAnchorElement>) {
    const el = ref.current
    if (!el) return
    const rect = el.getBoundingClientRect()
    // Pull toward the cursor at 30% strength, measured from the element centre.
    x.set((e.clientX - (rect.left + rect.width / 2)) * 0.3)
    y.set((e.clientY - (rect.top + rect.height / 2)) * 0.3)
  }

  function handleLeave() {
    x.set(0)
    y.set(0)
  }

  return (
    <motion.a
      ref={ref}
      href={href}
      className={cn(BASE, className)}
      style={{ x: sx, y: sy }}
      onMouseMove={handleMove}
      onMouseLeave={handleLeave}
    >
      {children}
    </motion.a>
  )
}
```

```tsx
export function Nav() {
```
